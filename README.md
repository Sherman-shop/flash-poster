# ✦ FlashPoster

> 轻松做一张好看的促销海报

适合咖啡店、奶茶店、花店和个体商家。输入文字，挑模板，下载高清 PNG。

**🌐 在线体验：** <https://Sherman-shop.github.io/flash-poster/>

## 使用方式

1. 直接双击 `index.html`，无需服务器或依赖。
2. 使用页面中的「示例」功能快速体验，填写真实数据后可导出结果。
3. 上传本目录**内部**全部文件到 GitHub 新建的公开仓库 `flash-poster`。
4. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
5. 等待部署后访问 `https://你的用户名.github.io/flash-poster/`。

## 技术要点

- Canvas 2D · 原生 JavaScript
- HTML / CSS / JavaScript，无安装、无构建、无外部 CDN。
- 独立的 **FlashPoster** 视觉主题，专属 CSS 与独立导航；不依赖其他四个仓库。
- 默认本地算法可用，⚙ 可选 OpenAI 兼容 API（DeepSeek 等）；API Key 仅存在本地浏览器。
- 使用在线 AI 时，请避免提交真实敏感客户数据至第三方服务。

## 演示与边界

内置规则引擎、模板和模拟器适用于创意辅助与原型演示，**不等于已验证的营销成效或真实 AI 推理**。预算预测是情景假设，须结合真实业务检验。
